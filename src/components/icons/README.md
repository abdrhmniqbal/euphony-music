# Generated icons

`src/components/icons/` (including `local/`) is **generated** by [`@monicon`](https://monicon.dev) from the icon source collection in `src/assets/icons`, configured by `monicon.config.ts` (`reactNative({ outputPath: "src/components/icons" })`).

- Do **not** edit these files by hand — regenerate them via the monicon build instead.
- They are ignored by `oxlint` (`.oxlintrc.json` `ignorePatterns`) and `oxfmt` (`.oxfmtrc.json` `ignorePatterns`) because they are generated.
